Dcompany（以下「当社」）は、お客様のプライバシーを尊重します。本ポリシーは、当社のウェブサイト（sector-31.com） およびゲーム Sector31 における情報の取扱いについて説明します。

メモアプリ AllMemo については、別途 AllMemo プライバシーポリシーをご覧ください。

お知らせ：Sector31 はまだリリースされていません。本ポリシーはゲームが情報をどのように取り扱う設計かを記載したもので、 リリース前に改めて見直し、更新します。

1. ウェブサイト

本ウェブサイトは静的な情報サイトです。アカウント登録を求めず、アクセス解析ツールを使用せず、当社独自のクッキーも設定しません。 本ウェブサイトは GitHub Pages 上でホスティングされており、ホスティング事業者である GitHub は、サイトの提供および保護のために IP アドレス等の技術情報を自社のプライバシーステートメントに従って処理することがあります。

メールでお問い合わせいただいた場合、当社はご返信の目的のみにメールアドレスとお問い合わせ内容を利用します。

3. 広告

Sector31 では、視聴により報酬が得られる任意の広告を提供することがあります。広告が含まれる場合、広告事業者（例：Google AdMob）が 自らのプライバシーポリシーに従って端末の広告識別子および関連情報を収集・処理することがあります。 法令上必要な場合は、パーソナライズ広告の表示前に同意をいただき、その内容を反映して本ポリシーを更新します。

当社はお客様の個人情報を販売しません。サービスの運営に必要な範囲でのみ、次のとおり提供します。

  • 公的機関 — 適用される法令が求める場合

ニックネーム、プロフィールアイコン、ランキング、他のお客様に送信したメッセージなど、ゲーム内で公開される情報は他のお客様が閲覧できます。

6. 保有期間と削除

当社は、アカウントが有効である間、およびサービスの提供に必要な期間、ゲームデータを保管します。

アカウントの削除：お客様はいつでも、ゲーム内（メニュー → 設定 → アカウント削除）または当社へのご連絡により （Sector31 アカウント削除のご案内をご覧ください）アカウントを削除できます。 削除をご請求いただくと、ニックネームはただちに解放され、ゲームの進行は停止します。 7日以内に再度ログインすると、アカウントは復旧します（ニックネームは新たに設定が必要となる場合があります）。 7日を経過すると、アカウントおよび個人情報は完全に削除され、復旧できません。 残っている有償のゲーム内通貨は返金されず、消滅します。

法令により保存する記録：次の記録は、他の個人情報と分別して以下の期間保存したうえで削除します。 起算点は退会日ではなく当該取引日です。

記録期間根拠法令（大韓民国）
契約または申込みの撤回等に関する記録5年電子商取引等における消費者保護に関する法律
代金決済および財貨等の供給に関する記録5年電子商取引法、国税基本法
消費者の苦情または紛争処理に関する記録3年電子商取引等における消費者保護に関する法律

その他の国の法令が保存を求める記録については、当該法令が定める期間保存することがあります。

削除の方法：電子的なデータは復元できない方法で削除します。

当社は、通信の暗号化および端末内のアカウント認証情報の安全な保管を含め、合理的な技術的・組織的保護措置を講じています。 送信や保存の方法に完全に安全なものはありませんが、当社はお客様の情報を保護するよう努めます。

お客様は、お住まいの地域の法令に応じて、個人情報の開示、訂正、削除、利用停止を求め、同意を撤回する権利を有する場合があります。 ご請求は下記のメールアドレスへご連絡ください。アカウントの確認のため、ゲーム内のニックネーム等の情報をお伺いすることがあります。

子どもの個人情報の処理に法定代理人の同意が必要とされる場合（例：大韓民国における満14歳未満）、当社はその同意を得るか、 または当該情報を処理しません。法定代理人は、子どもの情報の開示・訂正・削除を当社に求めることができます。 適切な同意なく子どもが個人情報を提供したとお考えの場合は当社までご連絡ください。当社は当該情報を削除するための措置を講じます。

当社の委託先は、お客様の居住国以外の国で情報を処理することがあります。 当社は、その場合もお客様の情報が本ポリシーに従って保護されるよう必要な措置を講じます。
