プライバシーポリシー

施行日：2026年9月17日（最終改定：2026年10月9日）

Dcompany（以下「当社」）は、お客様のプライバシーを尊重します。本ポリシーは、当社のウェブサイト（sector-31.com） およびゲーム Sector31 における情報の取扱いについて説明します。

メモアプリ AllMemo については、別途 AllMemo プライバシーポリシーをご覧ください。

1. ウェブサイト

本ウェブサイトは静的な情報サイトです。アカウント登録を求めず、当社独自のクッキーも設定しません。 一部のページでは、閲覧数を把握するため、表示されたページのアドレスを当社のサーバーに送信し、ページごと・日ごとの閲覧回数のみを集計しています。 この集計では IP アドレス、クッキー、端末情報などを保存せず、個人を特定することはできません。 本ウェブサイトは GitHub Pages 上でホスティングされており、ホスティング事業者である GitHub は、サイトの提供および保護のために IP アドレス等の技術情報を自社のプライバシーステートメントに従って処理することがあります。

メールでお問い合わせいただいた場合、当社はご返信の目的のみにメールアドレスとお問い合わせ内容を利用します。

3. 広告

Sector31 では、視聴により報酬が得られる任意の広告（Google AdMob）を提供しています。広告を視聴するかどうかは常にお客様の選択です。 Google AdMob は自らのプライバシーポリシーに従って端末の広告識別子および関連情報を収集・処理することがあります。 iOS では初回起動時にアプリのトラッキングを許可するかどうかをお尋ねし、許可されない場合は広告識別子を使用しない広告を表示します（受け取れる報酬は同じです）。 当社は、広告報酬が正しく付与されたかを確認するため、広告事業者から送られる広告取引識別子とアカウント識別子を保存します。

当社はお客様の個人情報を販売しません。サービスの運営に必要な範囲でのみ、次のとおり提供します。

  • 広告事業者（Google AdMob）— 上記3に記載の範囲で
  • 公的機関 — 適用される法令が求める場合

ニックネーム、プロフィールアイコン、ランキング、他のお客様に送信したメッセージなど、ゲーム内で公開される情報は他のお客様が閲覧できます。

6. 保有期間と削除

当社は、アカウントが有効である間、およびサービスの提供に必要な期間、ゲームデータを保管します。

アカウントの削除：お客様はいつでも、ゲーム内（メニュー → 設定 → アカウント削除）または当社へのご連絡により （Sector31 アカウント削除のご案内をご覧ください）アカウントを削除できます。 削除をご請求いただくと、ニックネームは直ちに他のお客様が利用できる状態となり、ゲームの進行は停止します。 7日以内に再度ログインすると、アカウントは復旧します（ニックネームは新たに設定が必要となる場合があります）。 7日を経過すると、アカウントおよび個人情報は完全に削除され、復旧できません。 残っている有償のゲーム内通貨は返金されず、消滅します。

法令により保存する記録：次の記録は、他の個人情報とは分離して以下の期間保存したうえで削除します。 起算点は退会日ではなく当該取引日です。

削除の方法：電子的なデータは復元できない方法で削除します。
